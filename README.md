# Cricket Gladiators

## Cricket Information Website

A group project developed as a cricket-themed information website as part of a Web Design module. The website was designed to provide an interactive and informative experience through a range of pages and features.

### Features

- 🏏 **Home Page** with navigation
- 🏆 **Greatest World Cup Matches in History** showcasing notable matches
- 🖼️ **Gallery** showcasing cricket-related content
- 🛒 **Shop** for cricket-themed products
- 🧠 **Quiz** with interactive questions
- 💬 **Comments** section
- 🗺️ **Sitemap**
- 👥 **About Us** page

### My Contributions

As part of the development team, I was primarily responsible for:

- Developing the **Quiz** functionality using JavaScript
- Designing and implementing the **About Us** page
- Designing and implementing the **Greatest World Cup Matches in History** page
- Combining the webpages and linking them together to create a cohesive website
- Creating a **Personal Contributions Page** documenting my work on the project

### Technologies Used

- **HTML5**
- **CSS3**
- **JavaScript**
